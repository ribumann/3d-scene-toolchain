# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Turn prompts, photos, process diagrams and site plans into editable browser
scenes through a traceable Blender and Idol pipeline.
Primary purpose is scene rendering for manufacturing digital-twin applications;
other domains are portability benchmarks. Live data overlays are a future
integration, not part of this initial milestone.

## Users

The proof-of-concept owner evaluates and corrects eleven cases across retail,
manufacturing, industrial facilities and a zoo.

## Capabilities and Constraints

Hybrid geometry and Gaussian appearance assets; source-linked interpretation,
selection, labels, saved layout edits and illustrative process/path animations.
No certified dimensions, physics/process simulation or guaranteed hidden geometry.
Per-runtime access to private image bytes and verified GPU model execution remain
explicit prerequisites. CPU readiness verified the configured secret's required
gated model access; that is not model inference.

## Operating Context

React Three Fiber/Three.js browser, Python service and worker, headless Blender
plus an authoring add-on. GPU inference runs separately from the browser.
The operator verified an Italy North Spot T4 on the intended external-tenant
subscription; actual model execution remains unverified. No credentials have
been exposed.

## Evidence on Hand

Three scenario prompts are in the repository. On 2026-11-11 the user supplied
all eight references: I01-I05 originals and G01-G03 AI-generated grocery,
semiconductor and zoo images. The coordinating operator validated and ingested
them privately through the existing API. Full originals and private metadata
remain in that operator's runtime. The user separately authorized eight
metadata-stripped public WebP previews for the read-only demo, clearly labeled
original-vs-AI-generated and reference-only. Intake is not reconstruction.
Repository is public and MIT licensed; uploaded media must not be published
without confirmed rights and scope review.

## Product Principles

- Distinguish observed, inferred, assumed and generated content.
- Persist user corrections and model/tool provenance.
- Report missing prerequisites and failures rather than fabricating success.
- Prioritize editable structure over unsupported photorealistic claims.
